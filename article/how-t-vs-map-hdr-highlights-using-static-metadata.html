How TVs Map HDR Highlights Using Static Metadata

This article examines how an HDMI television processes Static Metadata Type 1 to tone map peak High Dynamic Range (HDR) highlights. It details the specific data payload transmitted across the HDMI interface—including mastering display limits and content light levels—and explains the internal tone-mapping algorithms television processors use to compress out-of-range specular highlights onto consumer panels without clipping critical visual detail.

The Role of Static Metadata Type 1

Static Metadata Type 1 is defined under CTA-861 (specifically CTA-861.3 and later revisions) and SMPTE ST 2086. It is transmitted across an HDMI link via the Dynamic Range and Mastering (DRM) InfoFrame. When playing standard HDR10 content, the sending device (such as an Ultra HD Blu-ray player, streaming console, or PC) transmits a single set of metadata that remains constant for the duration of the video stream.

This metadata payload contains several critical variables used to calculate peak luminance:

  • SMPTE ST 2086 Mastering Display Color Volume: Defines the color primaries, white point, Maximum Display Mastering Luminance (MaxDML), and Minimum Display Mastering Luminance (MinDML) of the monitor used during color grading. MaxDML is typically set to 1,000, 4,000, or 10,000 nits (\(cd/m^2\)).
  • Maximum Content Light Level (MaxCLL): Represents the highest luminance value of any single subpixel across the entire program, expressed in nits.
  • Maximum Frame Average Light Level (MaxFALL): Represents the highest average frame luminance across the entire program.

Reading Absolute Luminance via the PQ EOTF

Unlike Standard Dynamic Range (SDR), which relies on relative gamma curves, HDR10 utilizes the Perceptual Quantizer (SMPTE ST 2084) Electro-Optical Transfer Function (EOTF). The PQ curve maps digital code values directly to absolute luminance targets up to 10,000 nits.

Because consumer televisions rarely match the peak luminance capability of mastering displays (consumer sets typically achieve between 400 and 2,000 nits), incoming PQ values representing bright highlights will exceed the physical capabilities of the display panel. The television reads the MaxCLL and MaxDML values from the DRM InfoFrame to identify the absolute ceiling of the content's highlight detail before rendering the image.

Calculating the Tone Mapping Target

Upon receiving the DRM InfoFrame, the television’s image processing pipeline compares the metadata against its own internal characteristics:

  1. Target Assessment: The processor checks MaxCLL. If MaxCLL is absent, corrupted, or listed as zero, the processor falls back to the MaxDML value to determine the upper luminance threshold.
  2. Capability Comparison: The display compares this incoming peak value to its own calibrated peak output (the maximum sustainable luminance of the panel, often bounded by power supply limitations and thermal management).

Highlight Compression and Roll-Off

When incoming peak highlights exceed the TV's native output, the television applies tone mapping to preserve highlight details (such as the texture of clouds, explosions, or reflections) rather than flatly clipping them to white.

  • The Knee Point: The TV maintains a 1:1 tracking of the PQ curve for low and mid-tone luminance up to a designated threshold known as the "knee point" (often around 60% to 80% of the TV's native peak capability). This preserves artistic intent for normal scene elements.
  • Compression Curve (Roll-Off): Above the knee point, the processor bends the PQ curve downward, compressing all input values between the knee point and the MaxCLL target into the remaining output headroom of the panel.
  • Hard Clipping vs. Soft Roll-Off: Depending on manufacturer implementation, the TV may use a "soft roll-off," smoothly scaling highlights so that 4,000-nit signals gradually compress down to the panel's limit (preserving highlight texture at the expense of highlight brightness). Alternatively, a TV might apply a steeper curve with a higher knee point, tracking 1:1 brightness longer but discarding fine detail near the very edge of the panel's peak output.

Through this algorithmic compression guided by Static Metadata Type 1, an HDMI television prevents clipping artifacts, avoids blown-out specular highlights, and translates high-luminance mastering data into an image optimized for the panel's native capabilities.
