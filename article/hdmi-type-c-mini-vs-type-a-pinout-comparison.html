HDMI Type C Mini vs Type A Pinout Comparison

This article provides a direct comparison between the HDMI Type A (standard) and HDMI Type C (Mini HDMI) connector pinouts. While both connectors share the exact same 19-pin electrical architecture and carry identical digital video, audio, and control signals, their physical arrangements and pin number assignments differ. Below is an explanation of these structural shifts, along with a complete pin-by-pin mapping table showing how Type C maps directly to standard Type A.

Key Architectural Differences

The standard HDMI Type A connector measures 13.9 mm × 4.45 mm, whereas the compact HDMI Type C Mini connector measures 10.42 mm × 2.42 mm, designed primarily for portable devices like cameras, tablets, and single-board computers.

Despite the reduction in physical size, Type C retains all 19 functional lines:

  1. TMDS Data and Clock Pairs: Both connectors feature four Transition-Minimized Differential Signaling (TMDS) channels (Data 0, Data 1, Data 2, and Clock). In Type A, the positive signal occupies the lowest pin number of a triad, followed by the shield, then the negative signal (e.g., Pin 1: Data2+, Pin 2: Shield, Pin 3: Data2-). In Type C, this layout is rearranged: the shield pin comes first, followed by the positive line, then the negative line (e.g., Pin 1: Shield, Pin 2: Data2+, Pin 3: Data2-).
  2. Control and Auxiliary Pins: Pins responsible for Consumer Electronics Control (CEC), Display Data Channel (DDC: SCL and SDA), Hot Plug Detect, and +5V power are also relocated across pins 13 through 19.
  3. Passive Compatibility: Because all signals, voltages, and data protocols are electrically identical, transitioning between Type A and Type C requires only a passive cable or adapter—no active conversion circuitry is needed.

Summary of Shifts

When building custom cables or troubleshooting custom hardware:

  • Differential lines: Type C swaps the shield and positive pins for all three data channels and the clock channel relative to Type A. The negative differential line consistently remains in the third position of each triad.
  • Ground and Utility: The DDC/CEC Ground line moves from Pin 17 on Type A to Pin 13 on Type C, shifting CEC down by one position (Pin 13 on Type A to Pin 14 on Type C).
  • Direct 1:1 Pins: Pins 15 (SCL), 16 (SDA), 18 (+5V Power), and 19 (Hot Plug Detect) maintain identical pin numbering on both connector form factors.
