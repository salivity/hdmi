What Does the HDMI Hot Plug Detect Pin Do?

The HDMI Hot Plug Detect (HPD) pin serves as an active hardware signaling mechanism that informs a source device when a sink display has been connected, disconnected, or requires re-authentication. Operating on Pin 19 of a standard HDMI Type-A connector, this line triggers the critical handshaking procedure between devices, initiating the exchange of Extended Display Identification Data (EDID) and High-bandwidth Digital Content Protection (HDCP) keys so video and audio can transmit correctly without rebooting either machine.

How the Hot Plug Detect Mechanism Works

The HPD line operates using basic low-voltage signaling, typically between 0V and +5V DC. The source device, such as a computer graphics card, Blu-ray player, or gaming console, continuously outputs +5V power along Pin 18 to power the sink device's internal communication circuitry.

Once the sink device—such as a television or monitor—is plugged in and powered, it asserts the HPD line on Pin 19 by pulling it high to roughly +5V (or a minimum threshold of 2.4V for TTL logic). Until this voltage is detected by the source, the source keeps its high-speed Transition-Minimized Differential Signaling (TMDS) or Fixed Rate Link (FRL) data lines inactive.

The Handshake Sequence

When the source detects a high state on the HPD pin, it carries out an orderly boot sequence across the display interface:

  1. Power Supply: The source delivers power via the +5V Power line (Pin 18).
  2. Sink Notification: The display pulls the Hot Plug Detect line (Pin 19) high.
  3. EDID Readout: The source reads the display’s EDID profile over the Display Data Channel (DDC), an I2C-based communication bus. This table tells the source the display's native resolution, refresh rates, color profiles, and audio capabilities.
  4. Content Protection Handshake: If protected media is to be played, the devices negotiate HDCP encryption keys across the DDC bus.
  5. Stream Initiation: The source begins transmitting active audio and video streams matched precisely to the monitor's supported formats.

The HPD Pulse and Display Resets

The HPD pin is not merely an on-off switch for physical insertion; it also manages active runtime communication via an intentional voltage interruption called an "HPD pulse" or "toggle."

If the sink device changes states—such as waking from sleep mode, switching internal inputs, or experiencing a clock synchronization failure—it briefly pulls the HPD pin low (typically for at least 100 milliseconds) before returning it to a high state. The source treats this drop as a temporary disconnect, which forces an immediate flush of the current video cache and triggers a fresh readout of the EDID and HDCP parameters.

Common Issues Related to Hot Plug Detect

Because the HPD pin dictates whether a video signal is permitted to transmit, hardware or software issues affecting this line can result in complete signal loss:

  • Sleep and Wake Failures: Some monitors fail to assert the HPD pin quickly enough when waking from low-power modes, leading the computer to believe no monitor is present and keeping display outputs disabled.
  • KVM Switches and Extenders: Switching away from an active machine using a mechanical or passive switch breaks the HPD connection. This causes operating systems like Windows to rearrange desktop icons, close open application windows, or shift audio devices. Active switches bypass this by using HPD emulators to fool the source into seeing a constant connection.
  • Cable Wear and Voltage Sag: In long passive HDMI runs, voltage drop along Pin 18 or Pin 19 can cause the HPD voltage to dip below the minimum logic threshold, resulting in intermittent screen blackouts or blinking.
