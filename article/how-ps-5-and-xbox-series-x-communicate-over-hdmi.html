How PS5 and Xbox Series X Communicate Over HDMI

Modern gaming consoles like the Xbox Series X and PlayStation 5 use the HDMI 2.1 specification to actively communicate their operational and rendering states to compatible displays. Through a combination of hardware handshakes, metadata packets, and dedicated protocols—such as Auto Low Latency Mode (ALLM), Variable Refresh Rate (VRR), and Extended Display Identification Data (EDID)—the console signals whether it is rendering a game, streaming a movie, or navigating the system dashboard. This communication enables connected televisions and monitors to automatically adjust picture modes, latency settings, and refresh cycles in real time to match the console's output.

The Initial Handshake: EDID and DisplayID

Before any gameplay begins, the console and the display establish a baseline understanding of capabilities via an initial handshake:

  1. Reading Display Capabilities: When connected, the console queries the display's Extended Display Identification Data (EDID) and DisplayID via the I2C-based Display Data Channel (DDC).
  2. Feature Detection: The display informs the console of its supported resolutions (e.g., 4K at 120Hz), color formats (RGB 4:4:4, YUV 4:2:2), HDR standards (HDR10, Dolby Vision), and HDMI 2.1 gaming features like ALLM and VRR.
  3. Establishing the Link: The console configures its HDMI transmitter to match the highest mutually supported specifications using Fixed Rate Link (FRL) signaling, which replaces the older TMDS technology to achieve bandwidths of up to 40 Gbps (PS5) or 48 Gbps (Xbox Series X).

Auto Low Latency Mode (ALLM)

The primary mechanism a console uses to declare that it is in a "gaming state" is Auto Low Latency Mode (ALLM).

  • Signaling Game Mode: When a user launches a game, the console generates a specific flag within an HDMI Consumer Technology Association (CTA-861) InfoFrame packet embedded in the video blanking interval.
  • Display Response: Upon reading this ALLM flag, the display instantly disables latency-inducing image post-processing features (such as motion smoothing, edge enhancement, and noise reduction) and shifts into its low-latency "Game Mode."
  • Media Playback Switching: If the user exits the game to stream video through an app like Netflix, the console clears the ALLM flag, prompting the TV to restore standard processing modes for better picture quality during passive viewing.

Variable Refresh Rate (VRR) and Frame Syncing

Gaming frame rates often fluctuate based on scene complexity. To maintain smooth motion without screen tearing, the console and display communicate frame timings continuously:

  • HDMI Forum VRR: Both consoles use HDMI Forum VRR (Xbox also supports AMD FreeSync) to control the display’s vertical blanking interval.
  • Dynamic Timing: Instead of pushing frames to a rigid 60Hz or 120Hz grid, the console's GPU transmits a frame the moment it finishes rendering. It embeds synchronization commands directly within the HDMI signal, telling the display precisely when to draw the next frame.

Source-Based Tone Mapping (SBTM) and HDR Metadata

To convey color and luminance states, the console sends Dynamic Range and Mastering InfoFrames alongside the video data:

  • Static and Dynamic Metadata: When outputting in HDR10, the console sends static metadata detailing peak brightness levels. For titles supporting Dolby Vision (on Xbox Series X), dynamic metadata is fed frame-by-frame.
  • Source-Based Tone Mapping (SBTM): This HDMI 2.1 feature offloads HDR tone-mapping from the display to the console. The display communicates its color range and luminance limits to the console, and the console's GPU pre-adjusts the rendering output to eliminate clipping in highlights or crushed shadow details before sending the pixels down the HDMI line.

Consumer Electronics Control (CEC)

At the system level, state changes are communicated via the HDMI-CEC channel on pin 13 of the HDMI connector:

  • Power and Input States: When a controller powers on the console, a CEC command alerts the display to wake from standby and automatically switch to the designated HDMI input.
  • Standby Sync: Putting the console into rest mode similarly transmits a signal that can trigger the display to shut down or revert to a previous source.
