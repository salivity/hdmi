HDMI 2.0b Hybrid Log-Gamma HDR Enhancement

The HDMI 2.0b specification introduced standardized support for Hybrid Log-Gamma (HLG), an advanced High Dynamic Range (HDR) format tailored for live television broadcasts. This article outlines the specific technological enhancement brought by HDMI 2.0b, detailing how it integrated HLG signaling into the existing HDMI pipeline, its underlying transmission standards, and its practical impact on consumer audiovisual hardware.

Prior to the release of HDMI 2.0b, the HDMI 2.0a revision had added support for HDR using the SMPTE ST 2084 Electro-Optical Transfer Function (EOTF), which powers HDR10 and relies on static metadata defined by CTA-861.3. While this was ideal for pre-recorded media like Ultra HD Blu-rays and streaming services, it was ill-suited for live broadcast environments due to bandwidth limitations and the complexity of generating and transmitting metadata in real time.

The critical technological enhancement in HDMI 2.0b was the inclusion of HLG signaling capabilities. Developed jointly by the BBC and NHK, HLG operates under the ARIB STD-B67 standard and is codified internationally under ITU-R BT.2100. Instead of relying on metadata to instruct a display on how to scale brightness, HLG combines standard dynamic range (SDR) and HDR into a single distribution signal using a hybrid transfer function—a conventional gamma curve for lower luminance levels and a logarithmic curve for higher luminance levels.

To convey this format between devices, HDMI 2.0b adopted the updated CTA-861-G standard. This update added a specific EOTF identifier code for HLG within the Dynamic Range and Mastering InfoFrame transmitted via the HDMI auxiliary data stream. When a broadcast receiver, set-top box, or media streamer receives an HLG signal, HDMI 2.0b allows the source device to transmit this identifier to an HLG-capable television, prompting the display to switch automatically to the proper decoding mode and render the expanded dynamic range.

This enhancement required no increase in the physical bandwidth of the interface, which remained capped at 18 Gbps. Because HLG relies on the transfer function rather than heavy metadata payloads, most consumer electronics manufacturers were able to add HDMI 2.0b compliance and HLG support to existing HDMI 2.0a hardware through simple firmware updates, facilitating the rollout of live 4K HDR sports and event broadcasts worldwide.
