Maximum Luminance Over HDR HDMI

The maximum luminance value that can be signaled across an HDR-compatible HDMI connection depends on the distinction between the underlying electro-optical transfer function (EOTF) standard and the physical metadata transmission container. Under standard HDR transmission protocols like HDR10, the signaling system targets a maximum luminance ceiling of 10,000 nits (cd/m²), defined by the SMPTE ST 2084 Perceptual Quantizer (PQ) curve. However, the underlying CTA-861 metadata container transmitted across HDMI interfaces can technically carry digital values well beyond this threshold.

The 10,000-Nit Standard Limit

High Dynamic Range (HDR) video carried over HDMI—beginning with the HDMI 2.0a specification and continuing through HDMI 2.1—relies primarily on SMPTE ST 2084 (PQ). The PQ curve is fundamentally mathematically capped at a peak white luminance of 10,000 cd/m² (nits). Consequently, content mastering, color encoding, and consumer target grading define 10,000 nits as the functional maximum luminance level that an HDR signal represents.

CTA-861 HDR InfoFrame Encoding

When an HDMI source device (such as a 4K Blu-ray player, gaming console, or PC) transmits HDR video to a display, it sends static metadata packets using the CTA-861-G / CTA-861.3 Dynamic Range and Mastering InfoFrame.

This InfoFrame communicates crucial brightness data via specific descriptors:

  • Maximum Display Mastering Luminance (MDML): Indicates the peak brightness capability of the monitor used to master the content.
  • Maximum Content Light Level (MaxCLL): Represents the highest light level of any single pixel across the entire video stream.
  • Maximum Frame-Average Light Level (MaxFALL): Represents the highest average frame brightness throughout the content.

Within the CTA-861 specification, these luminance values are transmitted as 16-bit unsigned integers, with each bit representing an increment of 1 cd/m². From a pure protocol and transport container perspective, a 16-bit unsigned integer allows for a theoretical maximum value of 65,535 cd/m² (\(2^{16} - 1\)).

Practical Application

Although the HDMI metadata architecture allows values up to 65,535 nits to be physically written into the InfoFrame, any value exceeding 10,000 nits falls outside standard SMPTE ST 2084 reference guidelines. Display processors encountering luminance metadata are configured to interpret values up to 10,000 nits to map the incoming signal appropriately to their native panel capabilities (tone mapping). Therefore, 10,000 nits is universally treated as the maximum practical luminance signaled across an HDR-compatible HDMI connection.
