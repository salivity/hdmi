Ground Stitching Vias for HDMI Differential Pairs

Routing high-speed HDMI differential lines across printed circuit board (PCB) layers disrupts the high-frequency return current path, leading to impedance discontinuities, signal degradation, and electromagnetic interference (EMI). When Transition-Minimized Differential Signaling (TMDS) or Fixed Rate Link (FRL) clock and data traces transition between layers, ground-plane stitching vias must be placed immediately adjacent to the signal vias. This article outlines the specific ground stitching via configurations, placement rules, and design considerations required to maintain return path continuity and signal integrity for HDMI interfaces.

The Necessity of Return Path Continuity

High-speed differential signals do not merely travel through copper traces; their electromagnetic fields propagate through the dielectric, relying on an adjacent reference plane to carry the high-frequency return current. The return current naturally follows the path of least inductance directly underneath the signal traces.

When a differential pair drops through a via to another layer, its reference plane changes. If the reference planes on both layers are at ground (GND) potential, the return current cannot jump between planes without a physical conductive path. Ground-plane stitching vias bridge this gap. Without them, the return current spreads across the board until it finds the nearest path, creating a large inductive loop that ruins impedance matching, generates common-mode noise, and causes radiated emissions that fail compliance testing.

Required Number and Configuration of Stitching Vias

For HDMI differential pairs, symmetry and proximity are critical to preserving differential balance. The required via configuration depends on the performance targets and available board area:

  • Two Ground Vias per Pair (Recommended): The optimal configuration places two ground stitching vias symmetrically on either side of the differential signal via pair. This creates a pseudo-coaxial structure that balances parasitic capacitance, minimizes common-mode conversion, and provides equal return paths for both the positive and negative signals.
  • One Ground Via per Pair (Minimum): In high-density interconnect (HDI) designs with severe routing constraints, a single ground stitching via centered adjacent to the differential pair is the absolute minimum requirement. However, this asymmetric arrangement can induce a slight phase skew and common-mode noise, making it less suitable for high-data-rate standards like HDMI 2.1 (up to 12 Gbps per lane).
  • Shared Ground Vias: When routing multiple HDMI lanes (such as Clock, D0, D1, and D2) together, ground vias can be placed between adjacent pairs to provide return paths while simultaneously serving as shielding to suppress inter-pair crosstalk.

Placement and Proximity Guidelines

The effectiveness of a stitching via diminishes exponentially as its distance from the signal via increases. Follow these strict placement constraints:

  • Distance: Place ground stitching vias as close to the signal vias as manufacturing design rules (DRCs) permit. The center-to-center distance between a signal via and its corresponding stitching via should typically be under 30 to 40 mils (0.75 mm to 1.0 mm). Any distance greater than this introduces parasitic loop inductance that degrades the signal's rise time.
  • Via Sizing: Use the same drill size and pad diameter for stitching vias as used for the signal vias (typically 8–10 mil drill, 16–18 mil pad). Matching dimensions ensures consistent thermal expansion and predictable parasitic inductance, which is generally around 0.5 nH to 1 nH per via.
  • Layer Spanning: Ensure the stitching via connects only the specific reference planes associated with the layer transition. For through-hole vias, connect the via barrel directly to the relevant planes with solid copper connections rather than thermal reliefs to minimize inductance.

Anti-Pad Optimization and Impedance Matching

Signal vias inherently introduce excess capacitance, which drops the local differential impedance below the standard 100-ohm target for HDMI. Introducing ground stitching vias adds further capacitance if not managed correctly.

To offset this capacitive discontinuity, implement an oval or merged anti-pad (clearance void) around the differential signal vias on any plane layers they pass through without connecting. The ground stitching vias should sit just outside the edge of this shared anti-pad. This configuration counterbalances the parasitic capacitance of the pads with the inductance of the via barrels, maintaining the targeted 100-ohm differential impedance through the entire vertical transition.

Transitions Between Different Reference Potentials

HDMI differential pairs should always be routed between layers that reference the same ground planes. If a stackup forces a transition between a ground plane and a power plane, a stitching via cannot connect the two directly. In that scenario, a high-frequency ceramic decoupling capacitor (such as 0.1 µF or 10 nF in a 0402 or 0201 package) must be placed immediately next to the transition to connect the GND and power planes for AC return currents. However, this approach adds significant parasitic inductance and should be avoided in HDMI designs in favor of maintaining consistent ground reference planes.
