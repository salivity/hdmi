HDMI AVI InfoFrame Quantization Range Flagging

An HDMI source communicates video color levels to a display by embedding metadata inside an Auxiliary Video Information (AVI) InfoFrame, defined by the CTA-861 standard. This article explains how the source uses specific data bytes and bit fields within the AVI InfoFrame to signal whether video data is transmitted in Limited Range or Full Range quantization. Correct interpretation of these flags ensures that the display maps black and white levels accurately, preventing crushed shadow details or washed-out contrast.

The Role of the AVI InfoFrame

During active HDMI transmission, metadata packets are sent within the horizontal and vertical blanking intervals, known as the Data Island period. Among these packets, the AVI InfoFrame carries critical structural information about the active video stream, including aspect ratio, colorimetry, pixel encoding, and quantization range.

RGB Quantization Range (Q Field)

When transmitting RGB video data, the source uses the Q field to declare the quantization range. The Q field occupies bits 2 and 3 of Data Byte 3 (DB3[3:2]) in the AVI InfoFrame payload.

The two-bit configuration is defined as follows:

  • 00 (Default): The sink relies on the standard timing specification. Typically, Consumer Electronics (CE) video formats default to Limited Range, while IT/VESA computer formats default to Full Range.
  • 01 (Limited Range): Explicitly indicates Limited Range. For an 8-bit signal, luminance and color components are mapped between levels 16 and 235 (allowing footroom from 0–15 and headroom from 236–255).
  • 10 (Full Range): Explicitly indicates Full Range. For an 8-bit signal, values span the complete numeric scale from 0 to 255.
  • 11 (Reserved): Not currently valid.

YCC Quantization Range (YQ Field)

Historically, YCbCr (YCC) formats were strictly limited range. However, with the introduction of the CTA-861-F specification, explicit signaling for YCC range was added using the YQ field. This field resides in bits 6 and 7 of Data Byte 5 (DB5[7:6]).

The two-bit mapping for the YQ field is defined as:

  • 00 (Limited Range): YCC components adhere to standard broadcast video ranges (Y from 16 to 235, Cb/Cr from 16 to 240 in 8-bit systems).
  • 01 (Full Range): YCC components occupy the full 0 to 255 range.
  • 10 (Reserved): Unused.
  • 11 (Reserved): Unused.

Display Handling and Fallback

When an HDMI sink receives the AVI InfoFrame:

  1. Explicit Flags (01 or 10): The sink overrides any default behavior and adjusts its internal color processing pipeline directly to match the flagged range.
  2. Default Flag (00): The sink evaluates the Video Identification Code (VIC) carried in Data Byte 4. If the VIC corresponds to standard CE video timings (such as 1080p60 or 4K60), it defaults to Limited Range. If the timing is recognized as a standard VESA PC resolution, it defaults to Full Range.

By transmitting these explicit bits in DB3 and DB5, modern HDMI sources eliminate ambiguity, ensuring that the display renders grayscale and chromaticity with accurate dynamic range.
