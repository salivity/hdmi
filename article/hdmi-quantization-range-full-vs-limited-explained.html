HDMI Quantization Range: Full vs Limited Explained

HDMI quantization ranges define how digital color and luminance values are mapped to a display, specifically categorized into Full (0–255) and Limited (16–235) dynamic ranges for standard 8-bit video. When the source device (such as a PC, console, or media player) and the receiving display (such as a TV or monitor) use differing ranges, a quantization range mismatch occurs. This mismatch severely degrades picture quality, producing either "crushed blacks" with blown-out highlights or an overly bright, washed-out image with elevated black levels.

Understanding Quantization Ranges

Digital video represents colors using discrete numerical values. For standard 8-bit RGB signals, the scale provides 256 possible shades per color channel:

  • Full Range (0–255): Utilizes the entire numerical spectrum. Value 0 represents absolute reference black, and value 255 represents peak reference white. This is the universal standard for personal computers, PC monitors, and standard desktop operating environments.
  • Limited Range (16–235): Restricts the primary visible image data to a narrower window. Value 16 serves as reference black, while value 235 serves as reference white. The values below 16 (footroom) and above 235 (headroom) were originally preserved in legacy broadcast standards to prevent signal clipping and allow for broadcast overshoot. This remains the native standard for consumer televisions, optical disc players, and standard video broadcasts.

The Two Types of Mismatches and Their Visual Flaws

An accurate image requires both the transmitting device and the receiving display to be synchronized to the same range standard. When they do not match, one of two visual flaws occurs:

1. Source is Full (0–255), Display is Limited (16–235)

  • The Visual Flaw: Crushed blacks and clipped highlights.
  • Why It Happens: The source sends shadow information between levels 0 and 15 and highlight detail between levels 236 and 255. However, the display treats value 16 as the absolute blackest floor and value 235 as the brightest ceiling. Consequently, all subtle details from 0 through 15 collapse into pure, undifferentiated black, and details from 236 to 255 clip into flat, solid white. The resulting picture features artificially high contrast, missing shadow depth, and obscured bright textures.

2. Source is Limited (16–235), Display is Full (0–255)

  • The Visual Flaw: Washed-out, milky image with faded contrast.
  • Why It Happens: The display expects true black to be delivered at value 0. However, the source's darkest intended value is 16. Because the display maps value 16 as a dark gray rather than black, the entire low-end range is elevated. Simultaneously, the display expects peak white at value 255, but the source maxes out at 235, preventing the display from reaching its full luminance. This creates a flat, hazy image where true blacks appear dark gray and overall contrast is significantly diminished.

Correct Configuration

To prevent these flaws, verify that both ends of the HDMI chain use matching parameters:

  • PC Monitors: Set both the source output and the monitor input to Full.
  • Televisions: Set both the source output and the TV input to Limited (often labeled as "Standard" or "Low" black level), unless the TV specifically supports and is manually set to "Full" or "High" for PC/console gaming modes.
  • Automatic Detection: Many modern HDMI devices offer an "Auto" setting. Ensure both devices support automatic signaling via HDMI info-frames so the handshake can correctly negotiate the matching range without manual intervention.
