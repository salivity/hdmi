How HDMI CEC Bus Arbitration Works

HDMI Consumer Electronics Control (CEC) is a single-wire, shared bidirectional bus that allows connected home theater devices to communicate using a single remote or unified command system. Because every connected device shares this single physical conductor, multiple devices can attempt to transmit data simultaneously. To handle these collisions without corrupting transmissions, HDMI CEC employs a hardware-level, non-destructive arbitration protocol based on Carrier Sense Multiple Access with Collision Detection (CSMA/CD), ensuring that the highest-priority message completes uninterrupted while losing devices yield immediately.

The Physical Bus and Signal States

The HDMI CEC line operates as an open-drain (or open-collector) bus pulled up to approximately +3.3V through a resistor. In this setup, signal states are asymmetrical:

  • Passive / Recessive State (Logical 1): The bus floats high because no device actively drives the line.
  • Active / Dominant State (Logical 0): A device actively grounds the bus, pulling the voltage low.

Because an active ground overrides a passive pull-up, a dominant '0' always overwrites a recessive '1' if both are transmitted simultaneously.

Timing and Collision Detection

Every CEC communication block begins with a synchronized Start Bit, followed by a Header Block containing the 4-bit Initiator Logical Address and the 4-bit Destination Logical Address.

CEC encodes bits using pulse-width modulation where each bit period begins with a falling edge (line pulled low):

  • A logical '0' requires the bus to be held low for approximately 1.5 ms.
  • A logical '1' requires the bus to be held low for a shorter duration of roughly 0.6 ms before being released to float high.

Because a logical '0' holds the line low longer than a logical '1', the '0' acts as the dominant state on the bus during the latter half of the bit period.

The Arbitration Process

Arbitration takes place during the transmission of the Header Block, specifically while devices output their assigned logical addresses:

  1. Simultaneous Transmission: If two or more devices detect an idle bus and simultaneously begin transmitting, they synchronize to the same falling edge of the Start Bit.
  2. Bit-by-Bit Comparison: As each device transmits its own logical address bit by bit, it simultaneously reads the actual voltage state of the CEC line.
  3. Conflict Identification: If Device A attempts to transmit a recessive '1' (releasing the line early) while Device B transmits a dominant '0' (holding the line low), the bus remains pulled low by Device B.
  4. Immediate Back-Off: Device A senses that the physical state of the bus (low) does not match the state it intended to transmit (high). Device A recognizes that it has lost arbitration, immediately shuts off its output driver, and switches to receiver mode.
  5. Uninterrupted Delivery: Device B detects no discrepancy between its intended output and the bus state. It continues transmitting its message entirely unaware that a collision occurred, with zero data loss or packet corruption.

Retransmission and Address Priority

Because '0' dominates over '1', devices with lower numerical logical addresses inherently possess higher transmission priority during simultaneous attempts. For example, a TV (typically assigned Logical Address 0000) will always win arbitration over a playback device (such as a Blu-ray player or streaming stick, typically assigned 0100).

Devices that lose arbitration must wait for the current message exchange to conclude. Once the bus returns to an idle state, the losing transmitter calculates a standardized Signal Free Time (a mandatory delay based on bit periods) before attempting to retransmit its frame.
