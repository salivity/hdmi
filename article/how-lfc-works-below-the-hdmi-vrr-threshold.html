How LFC Works Below the HDMI VRR Threshold

Low Framerate Compensation (LFC) is an adaptive sync technology that prevents stuttering and screen tearing when a game's rendering speed drops below the minimum refresh rate supported by an HDMI Variable Refresh Rate (VRR) display. Standard VRR synchronizes the monitor’s refresh cycle directly to the graphics processor, but hardware limitations establish a baseline threshold—often between 40Hz and 48Hz—under which the panel cannot natively operate. When framerates dip beneath this floor, LFC dynamically multiplies the frames sent to the display, artificially raising the effective frequency so the monitor remains within its active VRR operating window.

The VRR Threshold Limitation

HDMI VRR operates within a designated frequency window, commonly 48Hz to 120Hz on modern televisions and monitors. When a graphics processor outputs frames within this window, the display refreshes exactly once per frame. However, liquid crystals in display panels require a minimum refresh frequency to prevent image degradation, flickering, or voltage decay. If a system renders at 30 frames per second (FPS) without any compensation on a 48Hz–120Hz display, the screen cannot step down to 30Hz. Without intervention, VRR disengages entirely, causing the display to revert to a fixed refresh rate that introduces severe judder or screen tearing.

Frame Duplication and Dynamic Multipliers

LFC resolves this limitation using frame duplication. Rather than displaying a single unique frame once at an unsupported frequency, the graphics processor or display controller presents each rendered frame multiple times at an active, supported frequency.

The mechanism relies on dynamic integer multipliers calculated in real time:

  • 2x Multiplication: If a game renders at 30 FPS on a display with a 48Hz minimum threshold, LFC displays each unique frame twice. The panel refreshes at 60Hz (30 FPS × 2), which sits comfortably within the 48Hz–120Hz range.
  • 3x Multiplication: If performance degrades further to 20 FPS, the system displays each frame three times, driving the panel at 60Hz (20 FPS × 3).
  • Fractional/Adaptive Pacing: For variable framerates hovering just below the threshold (such as 42 FPS), LFC can adaptively vary the refresh timing between cycles to ensure the display refresh rate remains an exact multiple of the framerate, preventing pacing artifacts.

The 2:1 Window Requirement

For LFC to function effectively, the display hardware must satisfy a specific mathematical ratio between its maximum and minimum refresh rates. The maximum refresh rate must be at least double the minimum refresh rate (a 2:1 ratio or greater).

A display with a 48Hz to 120Hz range easily supports LFC because the maximum refresh rate (120Hz) exceeds twice the minimum rate (96Hz). This headroom gives the algorithm sufficient space to double or triple lower framerates. Conversely, a display with a narrow window, such as 40Hz to 60Hz, cannot support LFC because doubling 35 FPS would require a 70Hz output, which exceeds the display's maximum physical capability.

Visual and Performance Impact

By seamlessly handling sub-threshold framerates, LFC ensures that the user experience does not suffer an abrupt transition between variable and fixed refresh states. Screen tearing is entirely eliminated, and the jarring micro-stutter associated with crossing the VRR boundary is replaced with regular, evenly paced frame delivery. While LFC cannot reduce the higher input latency inherently caused by low base framerates, it preserves visual fluidity and image integrity during heavy performance drops.
