Why HDMI Type C and Type A Pinouts Are Inverted

This article examines why the ground and TMDS differential pair pinouts differ between standard HDMI Type A and Mini HDMI Type C connectors. In HDMI Type A connectors, the ground shield pin sits between the differential signals, whereas in Type C connectors, the positive and negative differential signals sit adjacent to each other with the ground shield placed between adjacent channels. This design change was implemented to enhance electromagnetic coupling, reduce crosstalk between separate channels, and simplify high-density printed circuit board (PCB) routing in compact devices.

Pinout Comparison: Type A vs. Type C

In a standard HDMI Type A connector, each TMDS (Transition-Minimized Differential Signaling) channel is pinned out in a Data+, Shield, Data- configuration:

  • Pin 1: TMDS Data2+
  • Pin 2: TMDS Data2 Shield
  • Pin 3: TMDS Data2-
  • Pin 4: TMDS Data1+
  • Pin 5: TMDS Data1 Shield
  • Pin 6: TMDS Data1-

In contrast, the HDMI Type C (Mini HDMI) specification shifts the shield pin to the beginning of each group, keeping the differential signals together:

  • Pin 1: TMDS Data2 Shield
  • Pin 2: TMDS Data2+
  • Pin 3: TMDS Data2-
  • Pin 4: TMDS Data1 Shield
  • Pin 5: TMDS Data1+
  • Pin 6: TMDS Data1-

Maintaining Differential Pair Coupling

TMDS relies on differential signaling, where high-speed data is transmitted using two complementary conductors (+ and -). For optimal signal integrity, these two conductors must be tightly coupled physically and electromagnetically.

The original Type A design separated the positive and negative traces of a single pair with an internal ground shield pin. In the much smaller Type C form factor, maintaining this separation degraded differential coupling. By placing the positive and negative pins directly side-by-side (Pins 2 and 3, Pins 5 and 6), Type C connectors allow differential pairs to route together tightly without being split by an intermediate ground pin.

Preventing Crosstalk Between Channels

In the Type A pinout, the negative line of one channel sits directly next to the positive line of the next channel without an intervening shield (for example, Data2- on Pin 3 and Data1+ on Pin 4). At high frequencies, this proximity creates electromagnetic interference (crosstalk) between unrelated data streams.

The Type C pinout solves this issue by relocating the ground shield to isolate adjacent pairs. Pin 4 (TMDS Data1 Shield) acts as a physical and electrical ground barrier between Pin 3 (TMDS Data2-) and Pin 5 (TMDS Data1+). This interleaving provides continuous channel-to-channel shielding, substantially lowering inter-pair crosstalk across the connector interface.

Optimizing High-Density PCB Layouts

Type C connectors were introduced primarily for portable electronics such as digital cameras, camcorders, and small media players. These devices feature crowded PCBs with minimal surface area for routing high-speed traces.

Routing split differential traces from a Type A pinout requires either complex trace fan-outs or multi-layer via transitions to maintain length matching. By keeping the differential pairs adjacent and placing the shield pins between pairs, Type C enables direct, parallel differential trace routing straight from the board into the connector pads, minimizing parasitic inductance and simplifying high-density board layouts.
