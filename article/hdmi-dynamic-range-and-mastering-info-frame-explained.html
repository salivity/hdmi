HDMI Dynamic Range and Mastering InfoFrame Explained

The HDMI Dynamic Range and Mastering InfoFrame is a specialized auxiliary data packet transmitted across an HDMI connection that informs a television how to properly process and display High Dynamic Range (HDR) video. By carrying critical metadata regarding the mastering environment and the brightness limits of the content, this InfoFrame enables an HDR TV to automatically switch into HDR mode and tailor its tone-mapping algorithm to match the physical capabilities of its panel without clipping specular highlights or crushing shadow detail.

Introduced alongside HDMI 2.0a and defined under the CTA-861.3 specification, this InfoFrame is embedded into the data islands of the HDMI stream during horizontal or vertical blanking intervals. When a source device—such as a 4K Ultra HD Blu-ray player, gaming console, or streaming box—outputs an HDR signal, it uses this mechanism to describe the video stream's dynamic range attributes to the connected sink device (the display).

The Dynamic Range and Mastering InfoFrame conveys several key technical parameters:

  • Electro-Optical Transfer Function (EOTF): This byte identifies the specific gamma or luminance curve applied to the incoming content. Standard values identify whether the stream uses traditional SDR gamma, SMPTE ST 2084 (Perceptual Quantizer, used for HDR10 and Dolby Vision), or Hybrid Log-Gamma (HLG). This triggers the television to switch from its default gamma curve to the appropriate PQ or HLG decoding curve.
  • Static Metadata Descriptor ID: This specifies the structure and version of the metadata payload being sent. For standard HDR10 content, this is defined as Static Metadata Type 1.
  • Mastering Display Color Primaries: These fields carry the precise normalized CIE 1931 \((x, y)\) chromaticity coordinates for the red, green, and blue primaries utilized by the reference mastering monitor during post-production. This data reveals whether the grade targets a color gamut like DCI-P3 or BT.2020.
  • Mastering Display White Point: These coordinates define the reference white point (typically D65) of the display on which the video was mastered, ensuring color temperature accuracy.
  • Mastering Display Luminance (MaxDML and MinDML): These values outline the physical capabilities of the reference display used by the colorist:
    • Maximum Display Mastering Luminance (MaxDML): Expressed in increments of 1 nit (\(\text{cd/m}^2\)), this indicates the absolute peak brightness achievable by the mastering screen (commonly 1,000 or 4,000 nits).
    • Minimum Display Mastering Luminance (MinDML): Expressed in ten-thousandths of a nit (\(0.0001\text{ cd/m}^2\)), this indicates the black level threshold of the mastering monitor (such as 0.005 or 0.0001 nits).
  • Content Light Level Metadata: While the mastering luminance describes the hardware used to grade the video, these values describe the digital code values present within the video file itself:
    • Maximum Content Light Level (MaxCLL): The luminance value of the single brightest pixel found anywhere across the entire program.
    • Maximum Frame-Average Light Level (MaxFALL): The highest average luminance calculated for any single frame across the entire presentation.

Consumer televisions rarely possess the capability to output the full 1,000 to 4,000 nits of peak luminance defined in mastering studios. By receiving this InfoFrame, the TV's internal video processor compares the MaxCLL, MaxFALL, and mastering display limits against its own native peak brightness and black level. It then computes a static tone curve that dynamically scales down out-of-range luminance values to preserve detail in bright areas while maintaining overall image contrast.
