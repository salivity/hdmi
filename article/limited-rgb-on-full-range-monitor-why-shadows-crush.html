Limited RGB on Full Range Monitor: Why Shadows Crush

Crushed shadow details occur when an HDMI display and video source disagree on how digital color values are mapped, causing distinct dark gray gradations to collapse into flat, featureless black. When a Limited Range source interacts with a monitor expecting or processing a Full Range signal, misalignment in the digital black floor causes near-black luminance steps to truncate or compress beneath the displayable threshold. This article explains the technical mechanics of dynamic range quantization, how coordinate mismatches clip luminance data, and why shadow details disappear.

Full Range vs. Limited Range Quantization

Digital displays use quantization levels to define luminance steps from black to white. In standard 8-bit color depth, there are 256 available integer values (0 to 255):

  • Full Range (0–255): Commonly used by PCs and computer monitors. Code 0 represents absolute reference black, while code 255 represents peak white. Every step in between represents an active, visible shade.
  • Limited Range (16–235): Historically developed for television broadcasting and consumer video equipment. Code 16 represents reference black, and code 235 represents reference white. The values from 0–15 (footroom) and 236–255 (headroom) are reserved for timing, synchronization, and overshoot data rather than active image detail.

The Mechanics of Shadow Crushing

Crushed blacks occur when the display engine or GPU improperly remaps or clips the lower end of the luminance spectrum.

When a monitor configured for Full Range receives an unscaled Limited Range signal, code 16 is displayed as dark gray instead of true black, resulting in washed-out contrast. However, severe shadow crushing occurs under two common misconfiguration scenarios between these standards:

  1. Improper Range Expansion (Double-Processing): If a source operating in Limited Range attempts to send signals to a Full Range display, software drivers or scalers often try to stretch the 16–235 range across 0–255. If this mathematical remapping rounds down aggressively or misinterprets the black baseline, values near code 16 (such as codes 17 through 25, which hold critical near-black details like fabric textures or dark environmental geometry) are pulled below code 0. Any values calculated below 0 are clipped entirely, turning nuanced shadows into uniform black.
  2. Display Clamping (Inverted HDMI Black Level Settings): Monitors and TVs often label range controls as "HDMI Black Level" (e.g., "Low" for Limited, "Normal/High" for Full). If the user sets the monitor's input interpreter to "Low" (Limited) to combat the washed-out look of an incoming Limited signal while the graphics pipeline attempts a Full Range output, the display enforces a hard cutoff at value 16. Any data sent between 0 and 15 is discarded, and the dynamic curve steepens sharply above 16, forcing near-black tones to render as zero luminance.

Quantization Loss and Gamma Shift

When digital levels are improperly mapped from Limited to Full:

  • Step Expansion: Spreading 220 discrete steps (16–235) over a 256-step space (0–255) requires interpolation. Non-linear rounding drops subtle gradations, turning smooth gradients into banding artifacts and pushing faint low-end steps directly into the noise floor.
  • Gamma Distortion: Because display gamma curves calculate luminance output exponentially based on the input code, an incorrect black point reference shifts the entire transfer function. The bottom portion of the gamma curve flattens completely against zero, eliminating the perceptual contrast necessary for the human eye to differentiate dark gray from pure black.

Correcting the Signal Path

To resolve crushed shadows, the dynamic range must match across the entire video pipeline. Setting the source output range and the monitor's HDMI black level to the same standard—either Full-to-Full (0–255) for PC environments or Limited-to-Limited (16–235) for standard broadcast hardware—ensures that code 16 is recognized correctly without truncating shadow data.
