How HDMI Transmits 16-Bit Deep Color Without Error

This article explains how HDMI architectures transport uncompressed 16-bit Deep Color video signals across physical links without suffering from quantization truncation errors. By leveraging higher Transition Minimized Differential Signaling (TMDS) clock ratios, specialized pixel-packing phases, and end-to-end EDID handshakes, HDMI preserves the complete 48-bit RGB or YCbCr color payload natively rather than rounding or discarding lower-order bits.

The Baseline: Standard 8-Bit TMDS Architecture

In standard HDMI video transmission (24-bit color depth, or 8 bits per channel across Red, Green, and Blue/Color Difference channels), data is serialized using 8b/10b encoding. Under this standard baseline, the TMDS character clock matches the pixel clock exactly (a 1:1 ratio). Each TMDS clock cycle transfers an 8-bit byte per color channel, encoded into a 10-bit transition-minimized symbol.

Because the underlying physical channels are designed strictly around 10-bit serialized symbols per lane, transmitting a higher bit depth cannot be achieved by simply sending wider symbols.

TMDS Clock Scaling for Deep Color

Beginning with the HDMI 1.3 specification, support for Deep Color introduced dynamic clock multipliers to accommodate 10-bit, 12-bit, and 16-bit color per channel.

For 16-bit color (48 bits per pixel total across three channels):

  • The total payload increases by a factor of 2.0 compared to baseline 8-bit color (48 bits ÷ 24 bits = 2.0).
  • The TMDS character clock rate is scaled directly by 200% relative to the original video pixel clock rate.
  • The physical transmission lanes operate at double the frequency, creating the necessary throughput to convey double the bit volume within the same temporal frame period.

Pixel Packing and Phase Mapping

Rather than truncating the 16-bit integer values to fit into an 8-bit container, HDMI fragments and distributes the 16-bit color words across consecutive TMDS characters using a defined pixel-packing algorithm.

Each 16-bit component is split into high and low bytes. Across the three primary data channels, the 48 bits of a single pixel are mapped into two successive 24-bit TMDS character slots:

  1. Phase 0: The source transmits the first group of data bits across TMDS channels 0, 1, and 2.
  2. Phase 1: The source transmits the remaining bits across the same channels during the next TMDS clock period.

Because the TMDS clock runs at twice the speed of the pixel clock, both phases complete within the timeframe of a single active pixel. Every bit—from the Most Significant Bit (MSB) down to the Least Significant Bit (LSB)—is explicitly transmitted over the wire.

Eliminating Truncation Errors via Protocol Synchronization

Quantization truncation errors typically occur when a processing pipeline maps a higher bit depth into a smaller bit container (e.g., dropping the lower 8 bits of a 16-bit sample, or applying lossy dithering). HDMI eliminates this issue through strict transmission handshaking:

  • EDID and Sink Negotiation: Before transmission begins, the source reads the Extended Display Identification Data (EDID) from the display device. The display explicitly signals its support for 16-bit Deep Color and its maximum TMDS clock rate via the HDMI Vendor-Specific Data Block (VSDB).
  • AV InfoFrames: The source inserts periodic Auxiliary Video InfoFrames into the HDMI blanking intervals. These packets declare the exact colorimetry, color space, and pixel-packing phase being used (e.g., specifying a 16-bit color depth).
  • De-serialization without Rounding: The sink uses the InfoFrame metadata to configure its internal de-packer. It reassembles the fragmented byte streams from Phase 0 and Phase 1 back into the original, discrete 16-bit color values before passing the data to the display panel's processing pipeline.

Through coordinated clock multiplication and serialized pixel packing, HDMI provides an end-to-end bit-exact pipeline, delivering full 16-bit color fidelity with zero numerical truncation or precision loss.
